## Integration delivered here

`tools/inference` connects to the existing configured chat-completions interface without publishing its private source. It requires the actual endpoint and exact model, accepts full program binaries plus hash-bound known-IDL/account/replay evidence, and produces only an untrusted proposal. It does not replace a required fine-tuned model with a generic model. No payment or actual inference request was invoked while implementing/testing it.

IDL candidates now receive JSON Schema and additional consistency/reference checks, replacing the old "JSON parses" admission shortcut. Full-byte evidence transport replaces the old 100-byte prompt sample. Unsupported IDL forms fail explicitly. These are candidate validation improvements, not proof of executable correctness.

The separate [automatic admission protocol](../tools/inference/ADMISSION.md) specifies trusted CI replay/conformance gates for automatic merge/deployment without human review. Root registry and CI orchestration are intentionally outside this tool's scope. Operational integration still requires access to the configured service/model and a live inference verification, followed by actual adapter replay/conformance before any admission.
